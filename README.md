# Mood Journal – Mental Wellness Tracker

## Project Overview

Mood Journal is a web-based Mental Wellness Tracking System developed using CodeIgniter 4 and MySQL. It allows users to register, log in, record their daily moods, write journal entries, view mood history, track weekly mood reports, and receive wellness suggestions. The application helps users monitor their emotional well-being and build healthy daily habits.

## Features

- User Registration
- User Login & Logout
- Daily Mood Selection
- Mood Journal Writing
- Mood History
- Weekly Mood Report
- Mood Score Display
- Wellness Resources
- About Page
- User Dashboard
- Secure Session Management

## How I Run the Project

#### Step 1
I created the **MoodJournal** project in Visual Studio Code.

#### Step 2
I started Apache and MySQL using XAMPP.

#### Step 3
I copied the project folder into the **htdocs** folder of XAMPP.

#### Step 4
I created the MySQL database named **moodjournal**.

#### Step 5
I imported the **moodjournal.sql** file into phpMyAdmin.

#### Step 6
I configured the database connection in the **.env** file.

#### Step 7
I developed the required pages:
- Home
- About
- Login
- Register
- Dashboard
- Add Mood
- Mood History
- Wellness Resources

#### Step 8
I created the Controllers, Models, and Views using **CodeIgniter 4 MVC architecture**.

#### Step 9
I implemented session management for secure login and logout.

#### Step 10
I ran the project using the CodeIgniter development server.
php spark serve

#### Step 11
I opened the application in the browser:
http://localhost:8080

#### Step 12
I registered a new user account and logged in.

#### Step 13
I tested all features:
- User Registration
- User Login
- Add Mood
- Write Journal
- View Mood History
- View Weekly Mood Summary
- Open Wellness Resources
- Logout
